Open Island 0.1.9 — Windows 安装/启动问题说明
=================================================

一、为什么会出现“Windows 已保护你的电脑”？
  Windows 会给“从网络下载”的文件打上“网络下载”标记（Mark-of-the-Web）。
  本安装包由个人开发构建，未购买微软 SmartScreen 认可的付费代码签名证书，
  因此首次下载运行时 SmartScreen 会提示“无法识别的应用”。这不是病毒。

解决方法（任选其一，1 最简单）

方法 1：解除单个文件的下载锁定（推荐）
  1) 右键  OpenIsland-Setup-0.1.9-win-x64.exe  →  属性
  2) 在“常规”页底部勾选“解除锁定”(Unblock)  →  确定
  3) 再双击安装即可，之后不再提示

方法 2：使用本压缩包内的“一键助手”
  1) 先对下载的压缩包本身：右键 → 属性 → 勾选“解除锁定” → 确定
  2) 解压本压缩包
  3) 双击   Unblock-and-Install.cmd
     · 自动解除文件夹内所有文件的下载锁定
     · 自动准备可写的临时目录并启动安装程序

方法 3：PowerShell 一行命令
  powershell -NoProfile -Command "Get-ChildItem \"$env:USERPROFILE\Downloads\OpenIsland*\" | Unblock-File"

如果在蓝色提示中已经打开：
  点击左上角“更多信息” → 右下角会出现“仍要运行”按钮 → 点击即可继续安装。

便携版 ZIP 也一样：
  下载后先右键 ZIP → 属性 → 解除锁定，再解压运行 OpenIsland.exe。


二、安装时报错：无法创建目录 ...\Temp\is-xxxx.tmp（错误 5: 拒绝访问）
  这是 Windows 用户临时目录（%LOCALAPPDATA%\Temp）权限异常导致的，
  不是安装包损坏；常见于安全软件锁定、账户迁移或系统优化工具。

  最快的解决办法（任选其一）：

  A. 直接用本压缩包里的 Unblock-and-Install.cmd
     它会把本次安装的临时目录改到可写位置（%LOCALAPPDATA%\OpenIsland\install-temp），
     并尝试修复默认 Temp 目录权限，然后再启动安装程序。

  B. 手动指定临时目录（命令提示符/资源管理器地址栏均可）：
       set TEMP=%LOCALAPPDATA%\OpenIsland\install-temp
       set TMP=%TEMP%
       mkdir "%TEMP%"
       OpenIsland-Setup-0.1.9-win-x64.exe
     也可以把 TEMP/TMP 指向 D:\Temp 等任意可写目录再运行安装包。

  C. 用管理员命令提示符修复默认 Temp 目录权限（修复后普通安装也不再报错）：
       takeown /F "%LOCALAPPDATA%\Temp" /R /D Y
       icacls "%LOCALAPPDATA%\Temp" /reset /T /C
       icacls "%LOCALAPPDATA%\Temp" /grant "%USERNAME%":(OI)(CI)F /T

  D. 直接使用便携版 ZIP（OpenIsland-0.1.9-portable-win-x64.zip）
     解压后运行 OpenIsland.exe，完全不经过安装器的临时目录。

  另外请检查“系统属性 → 高级 → 环境变量”中的 TEMP/TMP 是否指向一个
  不存在或无权限的路径；正常应为 %USERPROFILE%\AppData\Local\Temp。

关于正式分发
  自签名证书只适合个人/小范围使用。若要公开发布并彻底消除警告，
  需要购买由受信任 CA 签发的 EV 代码签名证书（微软 SmartScreen 对 EV 证书
  立即建立信任），然后执行：
    .\scripts\package.ps1 -PortableZip -Sign -PfxPath "你的证书.pfx" -PfxPassword "密码"
